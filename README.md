# RexUI Eternal

**RexUI Eternal** ist die Version von RexUI für **World of Warcraft: Forever**.

Eine komplette Benutzeroberfläche mit dem Ziel, ein einheitliches, übersichtliches und anpassbares Interface für World of Warcraft: Forever bereitzustellen.

## Aktuelle Version

**RexUI Eternal 1.4**

## Funktionen

RexUI Eternal enthält unter anderem:

- ActionBars
- UnitFrames
- GroupFrames
- Nameplates
- Bags
- Minimap
- QuestTracker
- Cooldown Manager
- StatusBars
- DataPanels
- MicroMenu
- RaidUtility
- Blizzard UI Skins
- Profile
- Profil-Import und -Export
- weitere Komfort- und Utility-Funktionen

## Profile

RexUI Eternal besitzt ein eigenes Profilsystem.

Vorhandene RexUI-Profile können über die Profilverwaltung importiert und exportiert werden.

Dadurch kann ein bestehendes RexUI-Layout schnell auf RexUI Eternal übertragen werden.

## Installation

1. Lade die aktuelle Version von RexUI Eternal herunter.
2. Entpacke das Addon in den `Interface/AddOns`-Ordner von World of Warcraft: Forever.
3. Starte World of Warcraft.
4. Aktiviere RexUI.
5. Richte ein neues Profil ein oder importiere ein vorhandenes RexUI-Profil.

## Entwicklung

Dieses Repository enthält den aktuellen Quellcode von **RexUI Eternal** für World of Warcraft: Forever.

RexUI Eternal wird unabhängig von der Retail-Version von RexUI entwickelt und an die technischen Möglichkeiten von World of Warcraft: Forever angepasst.
